# Implementation Plan: Frontend Foundation (Task 3)

This plan establishes the core architecture for the React + Chakra UI v3 frontend, including configuration, internationalization, and the main application shell.

## 1. Dependencies & Configuration

* **Install Packages**:

  * `i18next`, `react-i18next`, `i18next-browser-languagedetector`, `i18next-http-backend` (i18n).

  * `vite-tsconfig-paths` (Path alias support).

* **Configure Build System**:

  * Update `frontend/vite.config.ts` to support path aliases (`@/*`).

  * Update `frontend/tsconfig.app.json` to define paths.

## 2. Chakra UI v3 System Setup

* **Theme Configuration**:

  * Create `src/theme.ts` implementing the "o2mation Emerald" brand colors (`#00ff80`) and RTL support.

  * Configure the Chakra UI `Provider` component.

* **UI Components**:

  * Initialize the necessary Chakra UI v3 snippets (Provider, etc.).

## 3. Core Infrastructure

* **Networking (`axios`)**:

  * Create `src/lib/axios.ts`: Configure base URL and interceptors to attach the JWT token from `localStorage`.

* **State Management (`TanStack Query`)**:

  * Create `src/lib/query-client.ts`: Configure the global `QueryClient` with default options.

* **Routing**:

  * Create `src/router.tsx`: Define the main routing structure (Auth routes vs. Protected routes).

## 4. Internationalization (i18n)

* **Setup**:

  * Create `src/i18n.ts`: Configure `i18next` with React bindings.

* **Locales**:

  * Create `public/locales/en/translation.json`.

  * Create `public/locales/ar/translation.json`.

* **Language Switcher**:

  * Implement a mechanism to toggle between English (LTR) and Arabic (RTL), persisting preference.

## 5. Layouts & Shell

* **Auth**:

  * Create `LoginScreen` component (`src/pages/auth/Login.tsx`).

* **Dashboard**:

  * Create `DashboardLayout` (`src/components/layouts/DashboardLayout.tsx`) with:

    * Sidebar navigation.

    * Topbar with user profile and language toggle.

* **Connection Status**:

  * Create `ConnectionStatus` component to warn users when offline (critical for this system).

## 6. Integration

* Update `src/App.tsx` and `src/main.tsx` to use the new Providers, Router, and Theme.
