# ULTRATHINK Implementation Plan: "Oxygen Air" Employee Salary System

This plan executes a high-fidelity, frontend-only prototype using React and Chakra UI v3. The architecture prioritizes the "Oxygen Air" aesthetic (clean, spacious, trustworthy) and robust "functional" mocking without a backend.

## 1. Foundation & "Oxygen" Design System (The Avant-Garde UI)

**Goal:** Establish a bespoke visual identity that rejects generic templates.

*   **Dependencies:**
    *   `@chakra-ui/react`, `@emotion/react` (Core).
    *   `i18next`, `react-i18next`, `i18next-browser-languagedetector` (I18n).
    *   `react-icons` (Iconography).
    *   `zustand` (State Management - lightweight & fast).
    *   `nanoid` (ID generation for mock data).

*   **Theme Engine (`src/theme/`)**:
    *   **Typography:**
        *   **Headings:** "Outfit" (Geometric, modern, approachable).
        *   **Body:** "Plus Jakarta Sans" (Legible, high x-height, professional).
    *   **Color Palette ("Oxygen Emerald"):**
        *   Primary: `#00E074` (Vibrant Emerald) - Defined as `colors.oxygen` with full 50-950 scale.
        *   **Semantic Tokens:** Map `brand.solid`, `brand.subtle`, `brand.focusRing` to `oxygen` scale for Chakra v3 compatibility.
    *   **Component Overrides:**
        *   `Card`: "Air" variant – high border-radius (2xl), subtle border, softest shadow (`shadows.xs`), glassmorphism backdrop (`backdropFilter: 'blur(10px)'`).
        *   `Button`: "Pill" shapes by default.

*   **Configuration**:
    *   `src/main.tsx`: Wrap app in `ChakraProvider` and `LocaleProvider`.
    *   `vite.config.ts`: Path aliases (`@/*`).

## 2. Core Infrastructure: The "Phantom" Backend

**Goal:** Provide a fully functional experience (CRUD, Persistence, Calculations) via a robust service layer.

*   **Storage Service (`src/services/storage.ts`)**:
    *   Generic `LocalStorage` wrapper with type safety.
    *   Keys: `oxygen_employees`, `oxygen_payroll_history`, `oxygen_settings`.
*   **Domain Services**:
    *   `EmployeeService`: `getAll()`, `create()`, `softDelete()` (Archive), `restore()`.
    *   `PayrollService`:
        *   `calculateNetSalary(employee)`: Implements the "Golden Rule" (Hourly Rate = Monthly / 270).
        *   `closeMonth()`: Snapshots current state into history and resets transaction flags.

## 3. "Ultrathink" UI Architecture

**Goal:** Deep UX analysis for layout and interaction.

*   **Layout (`src/layouts/DashboardLayout.tsx`)**:
    *   **Sidebar:** Floating, glass-effect navigation. Collapsible for "Focus Mode".
    *   **Topbar:** "Context-Aware" header. Shows breadcrumbs and global actions (Language Toggle EN/AR).
    *   **Main Area:** `ScrollArea` with semantic padding.
*   **Routing**:
    *   `/`: Dashboard (Stats).
    *   `/employees`: Employee Grid.
    *   `/payroll`: Salary Engine & History.

## 4. Feature Implementation

### A. Dashboard (The "Cockpit")
*   **Components:**
    *   `StatsCard`: Custom `Stat.Root` with "trending" indicators (Chakra v3).
    *   `TeamPulse`: A horizontal scroll view of active team members.

### B. Employee Management (The "Roster")
*   **Components:**
    *   `EmployeeTable`: Advanced `Table.Root` with:
        *   **Avatar Grouping:** Visual department indicators.
        *   **Status Badges:** "Active" (Green), "On Leave" (Orange).
        *   **Actions:** "Soft Delete" with undo toast.
    *   `AddEmployeeDrawer`: `Drawer.Root` form with validation.

### C. Salary Engine (The "Core")
*   **Components:**
    *   `PayrollSheet`: A detailed breakdown view.
    *   `TransactionInput`: Quick-add buttons for "Overtime" or "Deduction".
    *   `ClosureWizard`: A 3-step `Dialog` process to "Close the Month" (Review -> Archive -> Reset).

## 5. Internationalization (RTL/LTR)

*   **Translation Files:** `en.json`, `ar.json`.
*   **Directionality:**
    *   Hook `useEffect` to sync `document.dir` with `i18n.language`.
    *   Chakra's `LocaleProvider` ensures all components (drawers, popovers) flip correctly.

## 6. Execution Order

1.  **Scaffold:** Vite + Theme System + Fonts.
2.  **Logic:** Storage + Service Layer (Mock Data).
3.  **Shell:** Layout + Sidebar + I18n.
4.  **Views:** Dashboard -> Employees -> Payroll.
5.  **Refine:** Animations + RTL Polish.
